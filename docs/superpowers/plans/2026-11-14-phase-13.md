# Phase 13: 3D painting

Implement the existing roadmap's UV0 base-color painting (up to 2048 pixels), brush/clone/eyedropper/restore, per-stroke undo/redo, protected pending strokes and saved variants.

Use CPU pixel editing with a live CanvasTexture on the existing Three.js viewer. This keeps edits reversible and uses the existing GLB material writer; a separate Blender paint process cannot provide interactive feedback. Painting targets a selected material on a static displayed source. Unsupported UV channels/transforms or image encodings must fail explicitly. UV-space brush footprints can cross adjacent islands; document this limitation rather than claim projection painting.

- [x] Raycast pointer painting and live texture preview in the existing viewer, restoring textures/controls on stop or source changes.
- [x] Session-safe draft store, pinned parent, asynchronous save as paint variant, project-save/close protection.
