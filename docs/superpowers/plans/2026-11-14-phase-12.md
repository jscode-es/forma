# Phase 12 Implementation Plan

**Goal:** Implement mesh inspection, retopology, UV and normals from `docs/phases.md`.
**Architecture:** Use a built-in Blender engine through the existing isolated job queue. Discover an installed Blender executable or choose it through a validated native dialog. Each modifying task produces a preview GLB linked to its source; inspection produces a report. Preserve the original, session/source safety and protected pending parents established in Phase 11.
**Scope:** Inspect degenerate faces, open borders, non-manifold edges and connected components. Retopology with a face budget and regenerated UVs. UV unwrap/pack with template export. Normals recalculation and baking from a chosen detailed variant.
**Constraints:** No commits, pushes, downloads or installs. Use current Blender 5.2 for real validation. Reject unsupported skinned/morph inputs rather than silently losing them. Report material/UV changes explicitly. No generation claims based only on fixtures.

- [x] Add validated Blender discovery/configuration, runtime/task contracts and safe template export.
- [x] Integrate mesh jobs with protected source parents, project switching and preview variants.

## Validation focus

Use known topology fixtures (closed, open, disconnected and degenerate); check retopology budgets, UV bounds and normal bake output. Verify cancellation/error handling, protected source variants and session changes. UV template export must only write an explicitly selected result through a native save dialog.
