# Phase 15: animation

Deliver the animation roadmap through the existing local renderer and validated desktop boundary: an independent SQLite clip library, procedural idle/walk/run presets, a per-bone TRS key editor with FPS/interpolation/undo/redo, validated bone mapping/retargeting and actual animated GLB variants. Playback changes only the viewer until saved as a variant; pending edits retain their source and participate in save/discard/close guards.

Portable clip data version 1 contains name, FPS, durationFrames, a named parent/rest-TRS skeleton and per-bone translation/rotation/scale tracks with frame/value keys and LINEAR or STEP interpolation. Quaternions are normalized. Bounds, unique mappings, parent compatibility and supported transforms are validated rather than claiming arbitrary-rig retargeting.
