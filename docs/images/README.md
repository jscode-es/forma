# Documentation screenshots

These are real captures of Forma, taken with Playwright against the built Electron app. The capture script uses a fresh temporary data directory, disables demo engines and imports a GLB through the normal application flow. It does not access existing user projects, activate engines or generate AI results.

| Image | Area |
| --- | --- |
| `studio.png` | Full studio: viewport, navigation, materials and versions |
| `references.png` | Multi-view reference slots |
| `materials.png` | Finish tab and material controls |
| `model-tools.png` | Mesh tools and LOD budgets |
| `retopology.png` | Independent Instant Meshes activation and quad budget |
| `export.png` | Engine-package export controls |
| `engines.png` | Engine catalog before activation |
| `settings.png` | Settings sidebar and general preferences |

## Refresh

From the repository root, with dependencies installed:

```bash
npm run fixtures
npm run build
node scripts/capture-docs.mjs
```

The script prints its temporary data directory. Captures use the dark theme and English UI so the same files can be shared by both manuals. Hardware detection and available disk space reflect the capture workstation, not minimum requirements. Review every image after changing the UI.
