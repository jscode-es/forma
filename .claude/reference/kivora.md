# Kivora reference

- Package: `@kivora/nextjs` (+ `@kivora/theme` if imported directly).
- Docs: https://www.kivora.pro/docs, installation: https://www.kivora.pro/docs/instalacion, themes: https://www.kivora.pro/docs/temas, agents: https://www.kivora.pro/docs/agentes
- Component groups: Foundations, Forms, Navigation, Panels and menus, Data, Feedback, Content, Layout, Multimedia, Configuration, Animations.
- Useful for Forma: `ResizablePanelGroup` (editor layout), `Tabs`, `Command` (command palette), `Sheet`/`Drawer` (settings), `Progress` and `Toaster` (job feedback), `FileUpload` (reference images), `Slider`, `Select`, `Textarea` (prompt), `Player` (animation preview), `DataTable` (asset library).
