# Test fixtures

`npm run fixtures` downloads the sample models used to test the viewer into `fixtures/models/` (git-ignored). Files are pinned to a commit of [KhronosGroup/glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets) and verified by SHA-256.

| Model | License | Why |
| --- | --- | --- |
| Avocado | CC0-1.0 (Microsoft) | Small PBR model with base color, normal and occlusion/roughness/metallic textures |
| ToyCar | CC0-1.0 (Guido Odendahl, Eric Chadwick) | Several meshes and advanced material extensions (clearcoat, sheen, transmission) |

Only add fixtures whose license allows redistribution without restrictions; record the source and license here.
